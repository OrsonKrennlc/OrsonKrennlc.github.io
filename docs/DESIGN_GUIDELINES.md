# Jerry Shen Portfolio 设计规范

> 版本：2.2 · 2026-09-29<br>
> 设计依据：[Portfolio Figma](https://www.figma.com/design/2uZp15YctvodAv6p7yW8sL/portfolio?node-id=0-1)<br>
> 适用页面：首页、关于、建筑列表与详情、交互列表与案例、摄影，以及沿用该系统的小工具页。

## 设计方向

以安静的编辑排版承托作品。页面结构依靠标题层级、留白、细线与图片建立节奏；深绿标记身份、导航和行动。作品图片使用设计稿原图，不叠加全站统一滤镜。网站界面统一使用英文。

## 基础令牌

| 用途 | 值 |
| --- | --- |
| 页面底色 `--paper` | `#F8F9F6` |
| 品牌绿 `--green` | `#02542D` |
| 正文 `--ink` | `#17251D` |
| 次要文字 `--muted` | `#627066` |
| 分隔线 `--line` | `#CBD2C9` |
| 内容最大宽度 `--content` | `1280px` |
| 项目详情内容最大宽度 | `1200px`，在 `1920px` 视口下居中，左右各留 `360px` |
| 桌面左右留白 | 最大 `80px`，随视口收缩；移动端 `20px` |

整体排版使用 Manrope，回退到系统无衬线字体。Anonymous Pro 用于项目编号、类别、日期与图注。Caveat 只用于页眉署名。标题常规字重为 500，当前导航项为 700。上述字体通过 CSS 加载，网络不可用时保持系统字体回退和相同布局。

## 网格与页面

- 所有页面的桌面页眉统一高 `96px`，移动端统一高 `72px`。首页、关于、建筑与交互列表、摄影及工具页的页眉吸附在视口顶部；首屏无阴影，向下滚动后才渐显阴影，回到顶部时移除。建筑与交互项目详情页的页眉随页面滚动。当前栏目用 700 字重、绿色和短下划线标记；子项目详情继承所属栏目的选中状态。小于等于 `768px` 时使用可展开菜单；菜单支持 Escape、焦点和 ARIA 状态。
- 首页主视觉为文字与人像双列，下方三个等宽入口卡片。三个卡片均以照片为封面，悬停或键盘聚焦时显示渐变图层与文字；触摸设备持续显示文字。移动端将人像放在文字上方，卡片纵向排列。
- 关于页面使用左右双列的自述、兴趣和履历；移动端改为单列。
- 建筑和交互列表使用两列 `620:400` 封面卡片，移动端单列。建筑详情的内容最大宽度为 `1200px`：主图占内容宽度，信息侧栏约 `260px`，与叙述相隔最多 `80px`，图片画廊双列。小屏详情改为上下排列。建筑文字由英文 `assets/arch/<id>/context.csv` 生成，绝不手工改写生成文件。
- 交互案例使用每个项目自己的强调色，但共享详情结构：引言、主图、章节索引、内容区及下一项目入口。案例内容同样限制在 `1200px`；桌面三列内容卡片，平板两列，移动端单列。手机屏幕必须与设计稿中的透明设备外框叠放。
- 摄影页按设计稿顺序陈列 18 幅作品，桌面三列、平板两列、窄屏单列；图注悬停或键盘聚焦时显示。
- 小工具页没有对应设计稿，沿用列表卡片、间距、字体和页脚规则，保留应用及源码入口。
- 通用绿色页脚包含一句拉丁语格言、相应页面的下一步入口和署名；关于页与摄影页的出口各自指向 GitHub 与 Unsplash。

## 交互与动效

- 可交互文字具有可见的焦点轮廓、44px 的最小操作高度，以及轻微的位移或透明度反馈。
- 导航悬停或聚焦时出现短下划线并轻微上移；移动菜单以透明度和位移展开，菜单图标旋转。站内 HTML 页面跳转有约 `220ms` 淡出和 `480ms` 淡入，页内锚点保持平滑滚动。
- 卡片图片悬停时最多放大约 `1.045` 倍，过渡时间约 `600ms`；页面锚点平滑滚动。
- 交互项目封面的照片缓慢放大，设备组合与封面文字轻微上移；设备的屏幕与外框作为一组移动，避免错位。键盘聚焦具有相同反馈。
- `prefers-reduced-motion: reduce` 关闭平滑滚动和显著过渡。动效只强调指向与层级，不干扰阅读。
- 不把整段文字嵌入图片。图像使用有意义的替代文本，纯装饰的设备外框使用空替代文本。

## 内容与实现约束

- 使用原生 HTML、CSS 和 JavaScript；不引入框架、打包器或运行时依赖。英文导航和页面文案直接写在各 HTML 文件中；`js/site-header.js` 管理移动菜单，`js/site-motion.js` 管理站内页面切换。
- 设计稿导出的原始图片放在 `assets/figma/`，动态页面通过 `js/figma-assets.js` 的节点映射引用。保留项目源数据与既有工具链接。
- 新增可见文案、页面元信息、`alt` 和 ARIA 标签时，只提供完整英文；站内链接不再携带语言参数。
- 提交前运行 `python scripts/build_arch_data.py --check`、`python scripts/validate_site.py`、对改动的 JavaScript 运行 `node --check`，再运行 `git diff --check`。
